# ALZ Repo Study Series

这个目录用于执行“一个 repo 一个文档”的逐步学习法。

## 学习规则

- 每次只解析一个仓库，完成一个“直接解读文档”。
- 每个文档优先讲清：仓库结构、关键文件作用、上下游关系、真实调用链。
- 通过当前仓库自测后，再进入下一个仓库。
